# Roadmap

## Near term

- expand negative and boundary-value policy tests;
- improve reviewer documentation and reproducibility;
- add structured examples for MCP tool authorization failures;
- document how evidence should be bound to immutable artifact identity.

## Integration track

- prototype verifiable artifact-signature integration;
- define TPM/TEE attestation verifier interfaces;
- model staged rollout and rollback state transitions;
- evaluate durable, tamper-evident evidence storage options.

## Research track

- compare deterministic policy gates with LLM-only governance decisions;
- measure false-allow/false-hold behavior under adversarial evidence inputs;
- investigate lifecycle evidence requirements for industrial Edge AI fleets;
- study least-privilege tool design for agentic release automation.

The roadmap distinguishes demonstrator semantics from production integrations and welcomes focused contributions with reproducible evidence.
