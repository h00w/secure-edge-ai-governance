# Community Q&A topics

Questions and reviews are welcome around the following topics:

- Why separate probabilistic AI recommendations from deterministic release authority?
- What evidence should be mandatory before releasing an AI model to an edge fleet?
- How should two-person approval interact with automation?
- Where should TPM/TEE attestation be verified in the release path?
- How should rollback authority and known-good state be modeled?
- How should MCP tools be bounded so an agent cannot bypass governance policy?
- Which failures should automatically cause a manual hold?

For questions that expose a security-sensitive weakness, use the repository security policy rather than a public issue.
