# Research questions

The playground is designed to make several research and engineering questions concrete and testable:

1. Which release decisions should remain deterministic even when AI agents participate in the workflow?
2. What evidence is sufficient to authorize an Edge AI deployment?
3. How should two-person approval be represented so identity duplication and approval replay fail closed?
4. How should attestation, signature, regression, risk, and drift evidence be bound to one exact deployment artifact?
5. How can agent tools expose useful automation without granting authority to override governance policy?
6. What telemetry and rollback evidence should be retained after deployment?

Contributions that turn one of these questions into a reproducible experiment, negative test, or architecture comparison are especially welcome.
