# Project discovery and adoption

This document explains how people can evaluate and share the Secure Edge AI Governance Playground without relying on marketing claims.

## Fast evaluation path

1. Open the live Streamlit demo.
2. Verify one valid release scenario.
3. Break one governance control (for example attestation or regression evidence).
4. Confirm the gate fails closed to `manual_hold`.
5. Inspect the corresponding policy implementation and test.

## Useful ways to support the project

- star the repository if it is useful to your work;
- open a technical question or issue;
- contribute a focused test or documentation improvement;
- share the live demo with engineers working on Edge AI, AI security, MLOps, DevSecOps, trusted computing, or agentic AI governance.

The goal is genuine technical adoption and independent verification, not artificial engagement.
