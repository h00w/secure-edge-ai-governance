# Collaboration opportunities

This project welcomes focused collaboration from engineers and researchers working on secure Edge AI, agentic AI safety, trusted computing, DevSecOps, MLOps, attestation, update security, and AI lifecycle governance.

## High-value contribution areas

- adversarial tests for fail-closed release gates;
- TPM/TEE attestation integration design;
- signed artifact provenance and verification;
- fleet rollout and rollback state-machine modeling;
- policy-as-code extensions;
- MCP tool authorization and least-privilege analysis;
- evaluation scenarios for drift, regression, and unsafe automation;
- accessibility and reviewer-experience improvements.

## Small collaboration suitable for a first PR

A good first collaborative change is to add one new negative test demonstrating that a specific missing or invalid piece of evidence results in `manual_hold`, with a short explanation of the associated security invariant.

Genuine co-developed changes should credit every contributor using GitHub's normal co-authoring mechanism.
