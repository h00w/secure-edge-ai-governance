# Security Policy

This project explores security controls for Edge AI and agentic systems. Please report suspected vulnerabilities privately to the repository owner rather than disclosing exploit details in a public issue.

## Scope

Security reports may include issues affecting authentication, authorization, attestation, policy enforcement, update integrity, rollback, secrets handling, or unsafe agent/tool execution.

## Reporting guidance

Include the affected component, reproduction conditions, expected versus observed behavior, impact, and any suggested mitigation. Avoid including production credentials, personal data, or sensitive customer information.

## Coordinated disclosure

Reports will be triaged, reproduced where possible, and addressed before public technical details are released. Security fixes should include regression tests or other evidence that the affected control remains enforced.
